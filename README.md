# Concesionario: prototipo de diseño

Prototipo de una página de venta de autos y motos. La marca («Altiva Motors»), los vehículos y los datos son de ejemplo.

Qué incluye:

- Visor 3D de 360° con autos y una moto modelados con código (Three.js).
- Modo de fotos reales: se cargan fotos del vehículo o un video de una vuelta completa y la página arma el giro en el navegador. Nada se sube a ningún servidor.
- Inventario con filtros, sección de consignación y WhatsApp como acción principal.
- Propuesta de identidad (paleta, tipografía, mapa del sitio y fases de trabajo).

Es un solo archivo, `index.html`. Se carga Three.js desde jsDelivr y las tipografías desde Google Fonts.
